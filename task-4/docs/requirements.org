**** UQ-001: Валидация отчета
  :PROPERTIES:
  :ID:       uq-001
  :TYPE:     USECASE
  :STATUS:   PROPOSED
  :CREATED:  2026-03-23
  :END:
- Действующие лица или системы:
    - Сотрудник склада
    - Система 
- Описание:
    - Сотрудник загружает CSV-отчет
    - Система валидирует данные
    - Если найдены ошибки
        - то система отказывает в обработке отчета и демонстрирует информацию о несоотвествиях.
        - иначе система подтверждает принятие отчета для обработки.

**** UQ-002: Пакетная обработка
  :PROPERTIES:
  :ID:       uq-002
  :TYPE:     USECASE
  :STATUS:   PROPOSED
  :CREATED:  2026-03-23
  :END:
- Действующие лица или системы:
  - Система
  - БД
- Описание:
    - система проводит глубокую валидацию в соответствии с бизнес-логикой, обогащает данные и сохраняет их в БД пачками (chunks).
    - Если во время записи произошел технический сбой (например, БД временно недоступна)
        - то система повторяет попытку несколько раз без дулирования работы. 
    - По истечению попыток система прерывает обработку. 
    - Администратор может перезапустить задачу с момента прерывания без дублирования данных.

**** UQ-003: Мониторинг
  :PROPERTIES:
  :ID:       uq-003
  :TYPE:     USECASE
  :STATUS:   PROPOSED
  :CREATED:  2026-03-23
  :END:
- Действующие лица или системы:
  - Система
  - Администратор
- Описание:
  - Система предоставляет отчет о результате:
    - сколько строк успешно загружено, 
    - сколько отклонено из-за ошибок в данных, и
    - сколько времени занял процесс.
  - Если в процессе обработки произошли ошибки
    - то Система отпавляет Администратору уведомление.
